# Carnet de raider

Carte perso pour noter mes trouvailles dans Arc Raiders, pensée pour l'iPad.

- Une capture par carte (Dam, Buried City, Spaceport, Blue Gate, Stella Montis, Riven Tides), importée depuis l'appli.
- Repères avec catégorie, danger, notes et compteur de fouilles.
- Tout est stocké sur l'iPad. Le bouton « Exporter » crée un fichier de sauvegarde à ranger dans Fichiers ou iCloud Drive.
- Fonctionne hors ligne une fois ajoutée à l'écran d'accueil (Safari → Partager → Sur l'écran d'accueil).

Projet fan non officiel.
